# 方法链、转置与共轭转置（量子计算的必备操作）

> 为什么单独写一份：**共轭转置是量子力学出现频率最高的矩阵操作**（`U†U = I`、`A† = A`），
> 而且 **MATLAB 用户在这里有一个著名的陷阱**。这个坑值得花 20 分钟彻底搞懂。

---

## 1. 直接答案

`ex0` 的 TODO 7：

```python
M_dagger = M.conj().T
```

拆开看是两步：

```python
M_conj = M.conj()      # 第一步：取共轭（虚部变号）
M_dagger = M_conj.T    # 第二步：转置（行列互换）
```

写成一行就是 `M.conj().T`。

---

## 2. Python 的"方法链"（chaining）

这是 Python 很常见的写法。关键在于：**`.conj()` 会返回一个新的数组，然后你继续对这个新数组调用 `.T`。**

```
M.conj().T
└┬┘ └─┬─┘└┬┘
 │    │   └─ ③ 对 ② 的结果取转置
 │    └───── ② 取共轭，得到一个"新的"数组
 └────────── ① 原来的矩阵 M
```

**等价写法**（完全一样，只是加了括号看得更清楚）：

```python
M_dagger = (M.conj()).T
```

**MATLAB 对照**：MATLAB 里你会写成嵌套函数形式
```matlab
M_dagger = ctranspose(conj(M));   % 或者直接 M'
```
Python 更喜欢 `M.conj().T` 这种"从内到外一路点下去"的链式写法。

> ⚠️ **重要**：numpy 的 `.conj()` 和 `.T` **不会修改 M 本身**，它们**返回新数组**。
> 所以你写完这两步后，`M` 还是原来的 M。（这一点和 Python 列表的 `.sort()` 不同——那个会改原列表。numpy 通常返回新数组。）

---

## 3. 什么是"共轭转置"

给定矩阵

$$M = \begin{pmatrix} 1 & i \\ 0 & 2 \end{pmatrix}$$

**第一步：共轭**（每个元素虚部取反）

$$M^* = \begin{pmatrix} 1 & -i \\ 0 & 2 \end{pmatrix}$$

**第二步：转置**（行列互换）

$$M^\dagger = (M^*)^T = \begin{pmatrix} 1 & 0 \\ -i & 2 \end{pmatrix}$$

这正是 `ex0` 里期望的 `[[1, 0], [-1j, 2]]`。

---

## 4. ⚠️ MATLAB 的 `'` 陷阱（必读）

**MATLAB 里 `M'` 不是"转置"，而是"共轭转置"！**

| MATLAB | numpy 等价 | 实际含义 |
|---|---|---|
| `M'` | `M.conj().T` | **共轭**转置（Hermitian 伴随） |
| `M.'` | `M.T` | 仅转置，**不取共轭** |

很多 MATLAB 用户以为 `'` 就是转置，实际上它是**共轭**转置——`.` 的有无是决定性的。
（好消息：这意味着你在 MATLAB 里写的 `M'` 语义是对的，只是换到 Python 时要写成 `.conj().T`。）

---

## 5. 为什么绝不能用 `.T` 代替 `.conj().T`

**对实数矩阵，两者结果相同；对复数矩阵，结果完全不同。**

而**量子门基本都是复数矩阵**（相位门、Y 门……），所以这个区别是致命的。

### 一个会真的判错的例子：S 门

$$S = \begin{pmatrix} 1 & 0 \\ 0 & i \end{pmatrix}$$

**用 `.T`（错误）：**

$$S^T = \begin{pmatrix} 1 & 0 \\ 0 & i \end{pmatrix} \quad\Rightarrow\quad S^T S = \begin{pmatrix} 1 & 0 \\ 0 & -1 \end{pmatrix} = Z \neq I$$

→ 你会得出"**S 不是酉矩阵**"的错误结论。

**用 `.conj().T`（正确）：**

$$S^\dagger = \begin{pmatrix} 1 & 0 \\ 0 & -i \end{pmatrix} \quad\Rightarrow\quad S^\dagger S = \begin{pmatrix} 1 & 0 \\ 0 & 1 \end{pmatrix} = I \quad ✅$$

→ S 确实是酉矩阵，这是正确的。

**这个坑会直接出现在 `ex2_gate_matrices.py` 的 TODO 1**（写 `is_unitary` 函数）。
如果你在那里写成 `matrix.T @ matrix`，S 和 T 门会被误判成"不是酉矩阵"，然后你会怀疑自己对量子力学的理解——
**其实是转置写错了，不是物理错了。**

**记住**：
- **酉性判据** → 用 `M.conj().T`
- **厄米性判据** → 用 `M.conj().T`
- 只要涉及复数矩阵，**永远用 `.conj().T`**，不要用 `.T`

---

## 6. 它在量子力学里的名字

| 叫法 | 符号 | 说明 |
|---|---|---|
| 共轭转置 | $M^\dagger$ | 最常用 |
| Hermitian 伴随 | $M^\dagger$ | 同一个东西 |
| dagger / 匕首 | $M^\dagger$ | 口语叫法（读作 "M dagger"） |
| adjoint | $M^\dagger$ | 数学系叫法 |

三个核心公式（全部基于它）：

$$\text{酉性：} \quad U^\dagger U = I \qquad \text{厄米性：} \quad A^\dagger = A \qquad \text{谱分解：} \quad A = \sum_i \lambda_i |i\rangle\langle i|$$

> 这就是为什么 `ex0` 的输出里写着：**"这个操作叫 'dagger'，在量子力学里到处都是"**。

## 8. 一句话总结

> **复数矩阵求"转置"时，永远写 `.conj().T`。**
> 只有当你**确实只想转置、不想取共轭**时才用 `.T`——而在量子计算里这种情况很少。
