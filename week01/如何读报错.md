# 如何读 Python 报错（以及 8 种常见错误）

> 这是编程里**最重要的单项技能**。会读报错的人自己就能解决问题，不会读的人每次都要求人。
> 花 15 分钟读一遍，省你以后几百次卡壳。

---

## 一、报错要**从下往上**读

Python 的报错叫 **Traceback（回溯）**。新手最容易犯的错是从上往下读，然后被一堆看不懂的文件路径吓到。

**正确读法：先看最后一行。**

```
Traceback (most recent call last):
  File "D:\...\ex0_matlab_to_python.py", line 95, in <module>
    v = np.numpy([1, 2, 3, 4, 5])       # <-- 换成你的代码
        ^^^^^^^^
  File "D:\anaconda3\Lib\site-packages\numpy\__init__.py", line 792, in __getattr__
    raise AttributeError(f"module {__name__!r} has no attribute {attr!r}")
AttributeError: module 'numpy' has no attribute 'numpy'
└─────┬──────┘ └────────────────────────┬─────────────────────────────┘
   错误类型                        错误说明
```

读三样东西：

| 顺序 | 看什么 | 你这次的例子 |
|---|---|---|
| **① 最后一行** | **错误类型 + 说明** | `AttributeError: module 'numpy' has no attribute 'numpy'` |
| **② `File "...", line NN`** | **哪个文件的哪一行**（**找你自己写的那个文件**，别管 numpy 内部的） | `ex0_matlab_to_python.py, line 95` |
| **③ 那一行下面的代码** | **实际执行的那句** | `v = np.numpy([1, 2, 3, 4, 5])` |

中间那些 `D:\anaconda3\Lib\site-packages\...` 是**库内部的路径**，不是你写的代码，**暂时可以完全忽略**。

## 二、报错的结构（看懂这个就不慌了）

```
Traceback (most recent call last):        ← 固定开头，意思是"从最外层到出错点"
  File "...", line NN, in <函数名>
    出错的那行代码
    ^^^^^^                                 ← 箭头指向具体的出错位置
错误类型: 错误说明                          ← 最重要的一行！
```

`^^^^^^^^` 箭头指向的是**问题最精确的位置**。
你这次箭头指向 `np.numpy` 里的 `numpy` —— 提示"这个属性名有问题"。

## 三、8 种最常见的错误

| 错误类型 | 中文意思 | 典型原因 | 例子 → 修法 |
|---|---|---|---|
| **AttributeError** | 属性不存在 | 函数名/方法名写错 | `np.numpy(...)` → `np.array(...)` |
| **NameError** | 名字没定义 | 变量名拼错、忘了定义、忘了 import | `print(vv)`（应为 `v`） |
| **TypeError** | 类型不对 | 数字和字符串相加、参数个数不对 | `"a" + 1` → `"a" + str(1)` |
| **SyntaxError** | 语法错误 | 少了冒号、括号不配对、中文标点 | `if x > 1` → `if x > 1:` |
| **IndentationError** | 缩进错误 | 缩进不一致（Python 特有，MATLAB 没有） | 统一用 4 个空格 |
| **IndexError** | 索引越界 | 访问了不存在的下标 | `v[5]` 但 `v` 只有 5 个元素（有效 0–4） |
| **KeyError** | 字典键不存在 | 字典里没这个键 | `d["x"]` 但只有 `d["y"]` |
| **ModuleNotFoundError** | 模块没装 | 没装包、包名拼错 | `import numpyy` |

## 四、怎么查"正确的函数名是什么"

不要靠猜。有三种方法：

### ① 在 VS Code 里用自动补全（最快）

输入 `np.` 然后按 **`Ctrl + 空格`**（或等它自动弹出），会列出所有可用函数。
继续输入 `arr`，就会看到 `array`。

### ② 用 `dir()` 列出所有名字

在终端里跑：

```powershell
python -c "import numpy as np; print([x for x in dir(np) if 'arr' in x.lower()])"
```

会输出类似 `['array', 'asarray', 'asanyarray', ...]` —— 一眼就看到 `array`。

### ③ 查官方文档

https://numpy.org/doc/stable/reference/

> **经验法则**：函数名猜错时，`AttributeError` 会明确告诉你"没有这个属性"。
> 这时正确反应不是继续猜，而是**用上面三种方法查一次**。

## 五、你接下来几个 TODO 最容易写错的地方

| TODO | ❌ 容易写错（MATLAB 思维） | ✅ 正确 | 原因 |
|---|---|---|---|
| **2** | `np.numpy([1,2,3])` | `np.array([1,2,3])` | 函数名是 `array` |
| **2** | `v.shape()` | `v.shape` | `shape` 是**属性**不是方法，**不加括号** |
| **3** | `v[0:2]`（想取 1,2,3） | `v[0:3]` 或 `v[:3]` | Python 切片**左闭右开**，`[0:3]` 取索引 0,1,2 |
| **4** | 忘了缩进 / 忘了冒号 | `for i in range(1, 11):` 换行后缩进 4 空格 | Python 用缩进代替 MATLAB 的 `end` |
| **5** | `x^2` | `x**2` | Python 的幂是 `**`，`^` 是"异或"（完全不同的东西） |
| **5** | 忘了 `return` | `return x**2 + 1` | 不写 `return` 函数返回 `None` |
| **6a** | `A @ B` | `A * B` | 逐元素用 `*` |
| **6b** | `A * B` | `A @ B` | **矩阵乘法用 `@`** ← 最大的坑 |
| **7** | `M.T.conj()` 或 `M.conj().T` | 两个都对 | 共轭和转置顺序无所谓（对矩阵也对易） |

### 关于 `shape` 不加括号（第 2 个 TODO 常错）

这是 Python 里**属性（attribute）**和**方法（method）**的区别：

```python
v.shape      # ✅ 属性：直接取值，不加括号
v.shape()    # ❌ TypeError: 'tuple' object is not callable
```

类比 MATLAB：MATLAB 里 `size(A)` 是函数调用（带括号）；
Python 里 `A.shape` 是"读一个属性"（不带括号），而 `len(v)` 才是函数调用（带括号）。

**判断方法**：如果不确定，先不加括号试试；报 `is not callable` 就去掉括号。

## 六、遇到报错的标准动作（4 步）

1. **看最后一行** —— 错误类型和说明
2. **找自己写的那一行** —— 跳过所有库路径
3. **对照第三节的表** —— 判断是哪类问题
4. **改 → `Ctrl+S` → 重跑**

**如果 4 步走完还是不会**：把**最后一行 + 你自己那个 File 行**复制发我。
不需要发整个 Traceback，也不需要截图。

## 七、两个心态提醒

1. **报错是正常的，不是失败。** 你写 100 行代码，报 20 次错是健康的。报 0 次错才可疑。
2. **不要靠猜修 bug。** 猜出来的修法下次还会错。**每次报错都问自己"报错在说什么"**——
   这个习惯的复利极高。
