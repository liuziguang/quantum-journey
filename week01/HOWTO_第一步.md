## 0. 先理解 `None` 是什么

`None` 是 Python 里"什么都没有"的意思。我在代码里用它当**占位符**：

```python
a = None          # <-- 换成你的代码
```

意思是："这里应该有一行代码，但我先留空，等你填。"

你的任务就是**把 `None` 换成真正的代码**。填完一个，重跑一次，对应的 `[TODO]` 就会变成 `[OK]`。

## 3. 改（完整示范）

把这两行改成：

```python
a = [10, 20, 30, 40, 50]
third = a[2]
```

### 为什么是 `a[2]` 而不是 `a[3]`？

因为 **Python 的索引从 0 开始**，而 MATLAB 从 1 开始：

| 元素 | 10 | 20 | 30 | 40 | 50 |
|---|---|---|---|---|---|
| **Python 索引** | 0 | 1 | **2** | 3 | 4 |
| MATLAB 索引 | 1 | 2 | **3** | 4 | 5 |

- MATLAB：`a(3)` → 30
- Python：`a[2]` → 30

**这是 MATLAB 用户最容易犯的错，没有之一。**

另外注意两点语法差异：
- MATLAB 用**圆括号** `a(3)`；Python 用**方括号** `a[2]`
- MATLAB 数组写 `[10 20 30]`（空格分隔）；Python 列表写 `[10, 20, 30]`（**逗号分隔**）

## 8. 关于缩进（Python 和 MATLAB 最大的结构差异）

MATLAB 用 `end` 结束代码块：

```matlab
for i = 1:10
    total = total + i;
end
```

Python **用缩进**（行首空格）表示代码块，没有 `end`：

```python
for i in range(1, 11):
    total_loop += i
```

⚠️ **冒号 `:` 和缩进都不能少**。VS Code 会自动帮你缩进，回车后照它给的走就行。
如果报 `IndentationError` 或 `SyntaxError`，99% 是缩进乱了。

> 缩进用 **4 个空格**（VS Code 默认），不要用 Tab 混着空格。
