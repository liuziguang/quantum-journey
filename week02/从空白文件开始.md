# 如何从空白文件开始写程序（四步骨架法）

> 你现在面对的是一个**完全空的文件**。这是刻意的设计。
> `ex0` 是"填空"——每个 TODO 只有 1–2 行，有人给你搭好架子。
> 而**真实的工作没有架子**。这份文档教的是一种可复用的方法，不是答案。

---

## 一、为什么给你一个空文件

| ex0 训练的能力 | `my_first_program.py` 训练的能力 |
|---|---|
| 认语法、翻译 API（`np.array`、`.conj().T`） | **把一个问题拆成步骤，再用代码实现** |
| 有人给你变量名和位置 | 变量名、函数划分、结构**全由你决定** |
| 报错能立刻定位到那一行 | 报错可能来自结构问题，要自己判断 |

**第二种能力才是真正的编程。** 所以这一步不给你任何脚手架。

---

## 二、❌ 不要这样做

| 错误做法 | 会发生什么 |
|---|---|
| 打开文件直接从第一行开始敲 | 写到第 10 行就迷失了——不知道自己写到哪、还差什么 |
| 想在脑子里把整个程序想清楚再写 | 内存不够用。人脑同时只能装 5–7 件事 |
| 一次写完 40 行再运行 | 一报错你根本不知道是哪一行的问题 |
| 卡住了就搜"Python 怎么排序"然后复制 | 这次能跑，下次还是不会 |

---

## 三、✅ 正确方法：四步骨架法

> **核心思想：先搭骨架，再填肉。每次只解决一个问题。**

---

### 第 1 步：把需求**抄成注释**

新建文件后，**第一件事不是写代码，是写注释**。

```python
# 需求：
# 1. 给定一个复数列 data
# 2. 打印每个元素的模长
# 3. 找出模长最大的元素，打印它和它的下标
# 4. 计算所有元素模长之和
# 5. 把整个列表按模长从大到小排序
```

**为什么这步最有用**：当你在第 3 步卡住时，抬头就能看到"我还差什么"。
这等于给自己画了一张地图。

> 💡 这一步还有个隐藏好处：**写中文注释比写代码轻松得多**，
> 能立刻破除"面对空白文件的恐惧"。

---

### 第 2 步：写**函数签名**，函数体全写 `pass`

`pass` 是 Python 的"占位符"，意思是"这里暂时什么都不做"。

```python
def abs_list(data):
    """返回 data 中每个元素的模长列表"""
    pass

def argmax(items):
    """返回最大值的下标"""
    pass

def total(items):
    """返回总和"""
    pass

def sort_desc(data):
    """返回按模长降序排列的 data"""
    pass


if __name__ == "__main__":
    data = [1+2j, 3-1j, 0+1j, 2+0j]
    # 这里先随便调用一下，看看程序骨架能不能跑
    print(abs_list(data))
```

**现在运行它。** 会打印 `None`——**这是对的，说明骨架没问题。**

> ⚠️ 很多人跳过这步。但这一步的价值是：**让你先确认"程序的形状"是对的，再填内容。**
> 就像盖房子先立柱子，而不是先砌一面墙。

---

### 第 3 步：**一次只实现一个函数**，实现一个跑一次

```python
def abs_list(data):
    """返回 data 中每个元素的模长列表"""
    result = []
    for z in data:
        result.append(abs(z))
    return result
```

保存 → 运行 → 确认输出是 `[2.236, 3.162, 1.0, 2.0]` → **再去做下一个。**

**永远不要一次实现两个函数。** 如果一次改两处然后报错，你不知道是哪一处的问题。

---

### 第 4 步：在 `if __name__ == "__main__":` 里串联

```python
if __name__ == "__main__":
    data = [1+2j, 3-1j, 0+1j, 2+0j]

    print("模长列表:", abs_list(data))
    print("最大值下标:", argmax(abs_list(data)))
    print("模长之和:", total(abs_list(data)))
    print("降序排序:", sort_desc(data))
```

**跑通了，再回头优化**（比如把 `for` 循环换成 numpy）。**先让它对，再让它好。**

## 四、完整演示：用一个**不同的**例子走一遍

> ⚠️ **这是演示方法，不是你的作业。** 你的作业是复数模长那个，别抄这个。

**需求**：统计一串数字里的偶数个数，并找出最大的偶数。

### 第 1 步：抄注释

```python
# 需求：
# 1. 给定一串数字 data
# 2. 找出其中所有的偶数
# 3. 打印偶数的个数
# 4. 打印其中最大的偶数
```

### 第 2 步：骨架

```python
def find_evens(numbers):
    """返回 numbers 中所有偶数的列表"""
    pass

def count_items(items):
    """返回列表的长度"""
    pass

def max_value(items):
    """返回最大值；如果列表为空返回 None"""
    pass


if __name__ == "__main__":
    data = [3, 8, 1, 6, 10, 7, 4]
    print(find_evens(data))
```

### 第 3 步：逐个实现

```python
def find_evens(numbers):
    """返回 numbers 中所有偶数的列表"""
    result = []
    for n in numbers:
        if n % 2 == 0:        # % 是取余数；偶数除 2 余 0
            result.append(n)
    return result
```

跑一下，确认输出 `[8, 6, 10, 4]`。然后：

```python
def count_items(items):
    """返回列表的长度"""
    return len(items)

def max_value(items):
    """返回最大值；如果列表为空返回 None"""
    if len(items) == 0:
        return None
    return max(items)
```

### 第 4 步：串联

```python
if __name__ == "__main__":
    data = [3, 8, 1, 6, 10, 7, 4]
    evens = find_evens(data)
    print("偶数:", evens)
    print("偶数个数:", count_items(evens))
    print("最大偶数:", max_value(evens))
```

**完成。** 全程每一步都能跑、都能验证。

## 五、卡住时的自问清单

**按顺序问自己这 5 个问题**，90% 的卡壳能被前三问解决：

1. **这个函数的输入是什么？输出是什么？**（各用一句话说清楚）
2. **我要做的那一小步，用中文怎么说？**（说出口）
3. **这句话里的每个词，对应 Python 的哪个操作？**
   - "每个元素" → `for x in ...`
   - "满足条件的" → `if ...`
   - "收集起来" → 先建空列表，再 `append`
   - "求和" → `sum()`
   - "最大的" → `max()`
   - "下标" → `enumerate()` 或 `for i in range(len(...))`
4. **能不能先写一个"最笨的版本"？**（哪怕用 `for` 循环、哪怕慢）
5. **我能不能把它拆得更小？**（一个函数拆成两个）

## 六、四个常见的"死法"

| 死法 | 症状 | 解药 |
|---|---|---|
| **想一次写完** | 写了 40 行，一跑全错，不知道从哪查 | 一次一个函数 |
| **不留注释** | 写到一半忘了自己要干嘛 | 第 1 步先抄需求 |
| **不测就往下写** | 错误累积三层，最后无法定位 | 实现一个跑一个 |
| **粘贴网上的代码** | 这次过了，下次还是不会 | 可以看，看完关掉页面自己写 |
